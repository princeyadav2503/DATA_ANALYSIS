# 📊 Diabetes Data Analysis & Visualization

This repository contains an exploratory data analysis (EDA) and visualization notebook for the **Pima Indians Diabetes Dataset**, built using Python and Pandas in Google Colab.

---

## 📌 Project Overview
The goal of this lab project is to analyze clinical data to discover patterns related to diabetes outcomes, clean potential invalid entries, compute statistical summaries, and visualize feature distributions.
